Privacy Policy

Last updated: 8 October 2026

This policy covers the personal Google OAuth client "rclone" in the OuttaSpaceTime project. Its only user is the owner of this site, who uses it with rclone to access his own Google Drive.

What data is accessed

The app asks for Google Drive access (scopes drive, docs and drive.metadata.readonly), so rclone can list, read, upload and change files in the user's own Drive.

How data is used and stored

  • Data goes directly between Google's servers and rclone running on the user's own computer.
  • No data is sent to, collected by, or stored on any server run by this site.
  • OAuth tokens are kept only in the user's local rclone config file.
  • No data is sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
