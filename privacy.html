Privacy Policy

Last updated: October 8, 2026

This policy covers the Google OAuth client that OuttaSpaceTime uses with rclone to access their own Google account (for example, to sync and back up files in Google Drive). The app is for personal use by its owner only. It is not offered to the public.

What data the app accesses

When the owner authorizes the app, rclone receives an OAuth token from Google and uses it to read, write and list the files that the granted scopes allow. That is the only Google user data the app touches.

How the data is used

Data moves only between Google's servers and the owner's own computer, to carry out the file operations the owner runs. The OAuth token is stored locally in the rclone configuration file on that computer.

What is not done with the data

  • No data is collected, logged or stored on any server run by the developer. There is no such server.
  • No data is sold, shared with or transferred to third parties.
  • No data is used for advertising, analytics or profiling, or to train AI or machine learning models.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page. Deleting the remote from the rclone configuration removes the stored token from the computer.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

For questions about this policy, contact OuttaSpaceTime on GitHub.
